# Pi Setup for GitHub Integration

## When the Pi is back online, run these commands:

### 1. Add GitHub as remote
```bash
ssh pi-fish
cd ~/Development/fish-guardian
git remote add origin https://github.com/mdvb1001/fish-guardian.git
git remote -v  # Should show both 'origin' (GitHub) and no old remotes
```

### 2. Rename branch to 'main' (to match GitHub)
```bash
git branch -M main
```

### 3. Pull from GitHub (to get PROJECT_CONTEXT.md and GIT_WORKFLOW.md)
```bash
git pull origin main --allow-unrelated-histories
```

### 4. Push Pi's commits to GitHub
```bash
git push -u origin main
```

### 5. Verify setup
```bash
git remote -v
git log --oneline -3
```
